# v0.9.1-codex — Codex-style UI for pi-web

First tagged release of this personal fork. Based on upstream pi-web `v0.9.1`
(commit `ef1de89`), with a project-first interface redesigned after Codex.

> ⚠️ Personal fork, not the official project. Upstream:
> [agegr/pi-web](https://github.com/agegr/pi-web).

## ✨ Highlights

### Codex-style sidebar
- Conversations render as **single-line** rows; time, message count, and branch
  move into the hover tooltip, and actions only appear on hover.
- Rows are grouped **by project** with indented conversations.
- Each project shows its **newest 5 conversations**; the rest sit behind
  “Show N more” / “Show less”.
- Pinned projects and conversations, reorderable by drag.
- Removed the duplicate “New chat” row and the always-on “Git repo root only” hint.

### Project lifecycle
- **Create project** dialog: name + source folder, then start chatting.
  Projects with no chats stay visible as “No chats yet”.
- **Delete project**: deletes the project and **all of its conversation history**
  (subagent sessions are cascaded). The folder on disk is never touched.
- **Archive**: archive a whole project (its conversations go with it) or a single
  conversation. Soft-hide with a dedicated dialog; restore anytime.

### Automatic session titles
- A newly started conversation is titled from its **first user message** — no
  button to press. Browsing old conversations never spends title tokens, and
  renamed conversations are never overwritten.

### Native folder picker
- The create-project dialog opens **macOS Finder** (via `osascript`), falling
  back to the in-app directory browser on other platforms or headless hosts.
  The AppleScript prompt is sanitized against injection.

### Local launcher
- Launch cwd becomes the default workspace; a standalone Chrome app window on
  macOS; an instance manager page at `/instances.html`; costs shown in CNY.

## 🧱 Data

New state lives next to pi's session files:

| File | Contents |
| --- | --- |
| `~/.pi/agent/pi-web/projects.json` | Created projects |
| `~/.pi/agent/pi-web/archive.json` | Archived projects / conversations |
| `~/.pi/agent/pi-web/pins.json` | Pinned projects / conversations |
