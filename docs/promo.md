## Hacker News — Show HN

```
Show HN: I rebuilt pi-web's UI to feel like Codex

pi-web is the local browser UI for the pi coding agent
(https://github.com/earendil-works/pi). It's great, but the sidebar lists every
conversation in one dense tree, which gets crowded once you have a few projects.

So I forked it and redesigned the sidebar after Codex:
- single-line conversation rows, actions only on hover
- grouped by project, newest 5 shown with "show more"
- create/delete/archive projects (deleting a project also removes its chat
  history, but never the folder on disk)
- automatic session titles from the first user message
- native macOS Finder for picking a project folder

It reuses pi's existing config/session files (~/.pi/agent), so nothing is lost.
MIT, feedback welcome.

https://github.com/huangzx8090/pi-web
```

```
标题：给 pi 的网页版 pi-web 做了一个类 Codex 的界面

pi-web 是 pi coding agent 的本地浏览器界面，功能很全，但侧边栏把所有对话平铺在一起，

- 新建对话根据第一条消息自动生成标题
- macOS 下选文件夹直接弹 Finder

和 pi 共用 ~/.pi/agent，历史对话不丢。MIT。

仓库 / 截图：https://github.com/huangzx8090/pi-web
```
